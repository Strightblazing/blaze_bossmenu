**Blaze Boss Menu · Update v1.2.2**

**New admin menu: `/bossmenuadmin`**
• All admin tools in one place: any job's boss menu, points, Show zones, debug, test tools, settings
• The boss menu is roleplay only now: at desks and in the radial menu, admins get their real rank (checked on the server)
• Separate **Boss admin** entry in the radial menu for admins

**Points: invisible, a PED or a prop**
• Pick what stands at a point: PED (model + idle animation), prop, or nothing
• PEDs stay put: no wandering, fleeing or reacting
• Targeting aims at the PED / prop itself, not the floor
• **Change look** on existing points without deleting them

**Placing points**
• Live preview: zone ring at its real size, see-through PED / prop exactly where it will stand
• Mouse wheel = size, ← → = rotate, Page Up / Down = height
• New placement card, the HUD hides while you place (works with your HUD resource)
• **G** copies a ready config.lua line instead of saving

**Fixes & polish**
• One [E] prompt for the nearest point (no stacking, no double opening)
• Receptionist can be targeted
• Debug panel: move + resize, saved per PC
• Lighter on clients, small cleanups
• New Blaze Scriptworks startup banner

**Updating:** replace the folder and keep your config.lua (new options are optional). Database updates itself. Admin tools moved from `/bossmenu` to `/bossmenuadmin`.
